# Product

## Register

product

## Users

Dungeon masters running D&D or TTRPG sessions who need to quickly describe a random NPC's appearance on the fly. Shared tool for GMs to download and use at their own tables. The context is active play: a GM glancing at a screen while the party approaches a stranger, needing a vivid description in seconds.

## Product Purpose

A random NPC ancestry and physical description generator that pulls from a GM's custom location data and ancestry lists. Produces flavor text ("You encounter a...") instantly, reducing improvisation pressure and adding worldbuilding texture to encounters. Success means a GM can use it mid-session without breaking immersion or flow.

## Brand Personality

Vintage, tactile, immersive. It should feel like a document pulled from the game world itself, not a tool built outside it. The GM is consulting a handwritten codex, not a web app.

## Anti-references

- Roll20 / Fantasy Grounds: cluttered VTT UI, dated widgets, information overload
- Video game UI: dark leather textures, glowing runes, neon stat bars, HUD-style elements
- Generic SaaS / modern app: Inter font, Tailwind defaults, blue/white product chrome, rounded cards

## Design Principles

1. **The tool disappears**: UI elements exist to deliver the description. Nothing should distract from the generated text.
2. **Authentic materials over ornamentation**: real texture, worn paper, ink — not simulated fantasy chrome.
3. **Speed is immersion**: a GM should get what they need in one click, with no friction.
4. **Data as lore**: debug output, JSON views, and ancestry lists should feel like appendices in a sourcebook, not developer scaffolding.

## Accessibility & Inclusion

Standard legibility for a personal/shared tool. Ensure sufficient contrast on parchment backgrounds where the text is the product.
